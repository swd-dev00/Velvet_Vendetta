# Build Assist Agent v0.1.0

Download **BuildAssistAgent_0.1.0.zip** in this folder, then extract it.

The ZIP contains the installable Unity package, complete editable source, installation instructions, checksums and validation report. In Unity, install `BuildAssistAgent_0.1.0.tgz` through Package Manager, then open **Window > AI > Build Assist Agent** and configure Codex in Settings.

This is an initial development package. All 36 core checks and the .NET Standard 2.1 compatibility build passed. Compilation and live behavior in Unity 6.3 have not been verified. Nine Editor integration tests are included for that validation.

The SHA-256 of the complete download is recorded in `SHA256SUMS.txt` beside it.
